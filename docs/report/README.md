# Original write-up

`callosum-speedrun-report.pdf` (three pages) and `callosum-evidence-packet.pdf`
(figures and captions) describe the original single-A100 experiments behind the
README's results table. They link to run directories and analysis scripts from the
original research repository, [aime-bench](https://github.com/devYaoYH/aime-bench), and are **not part of this
repository** (the raw attempt archive was left out to keep it small). The evidence they
cite is there; treat the PDFs as a historical record.
